# Kubernetes Lab

A hands-on Kubernetes infrastructure project focused on
automation, container orchestration, and DevOps practices.

## Project Overview

This repository contains the configuration files, automation
scripts, Kubernetes manifests, and documentation used to build
and manage a Kubernetes lab environment.

## Infrastructure

- 1 Kubernetes Control Plane Node
- 2 Kubernetes Worker Nodes
- Ansible for configuration management and automation
- Sonatype Nexus Repository for package and container image caching

## Technologies

- Linux
- Git
- Ansible
- Docker
- Kubernetes
- Sonatype Nexus Repository
